# ネスペ午後 単語テスト（ローカル保存版）

ネットワークスペシャリスト試験の午後試験・重点単語帳（レイヤー別、全219語）を使った4択の用語テストアプリ。単一のHTMLファイル＋JavaScriptで動作する。

## 使い方

- `index.html` をブラウザで開くだけで使える（GitHub Pagesで公開してもそのまま動く）。
- 出題モード：全範囲／穴埋め実績のある語のみ／⚠付き用語／レイヤー別／苦手だけ。10・20・30問セット。
- 「一度出題した問題は出さない」設定：オンにすると未出題の語だけが出題され、残り語数が表示される。表示された問題は回答しなくても出題済みになる（「苦手だけ」は対象外）。設定と出題済みの記録はブラウザのローカルストレージに保存される。
- 学習記録（用語ごとの正誤・正答率・苦手リスト・テスト履歴）はブラウザのローカルストレージに保存される。端末やブラウザをまたいだ同期はされない。

## 収録データ

- 単語帳の全219語（穴埋め出題実績バッジ付き112語、公式採点講評の⚠ノート21件）。
- 設問ルール：定義文に用語名が含まれる語は「説明→用語」形式では出題しない／紛らわしい誤答を除外／定義が断片的な語には設問専用の言い換え文を用意。
